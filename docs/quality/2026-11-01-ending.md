# 마지막 엔딩 · 남겨진 편지

감사 문구와 크레딧의 인사 문장을 제거했다. 최종 화면은 「남겨진 편지」와 남편의 마지막 독백을 중심으로, 수신인·미전달 도장·보존 기록을 같은 화면에 배치한다. 기존 사고 차량의3D 배경을 유지하고 명조 제목/빛바랜 종이색/먹색 여백과 낮은 시간 흔적으로 정리했다. PC는2열, 좁은 화면은1열로 쌓는다. 외부 이미지·폰트·효과음·지속 애니메이션을 추가하지 않는다.

최종 편지/후일담 본문과2/8/14초 서사 전환·40초 마무리, BGM·기록·저장·재시작 로직은 유지한다. 전체 편지와 마지막 기록은 native details이며, 크레딧의 여성 흐느낌 CC BY3.0 링크를 보존하고 새 직접 작곡 추격곡도 표시했다. 다시 시작/후일담 다시 보기와 건너뛰기 동작은 그대로다. 장식 시각 요소는 aria-hidden으로 숨긴다.

## 화면 검증

- 실제 게임의 B1 차량 저장→귀신/트럭 사고→후일담→최종 페이지를 실행했다.1280×720과390×844에서 새 구성·감사 문구 제거·실제 배경을 확인했다.
- Tab 순서는 다시 시작→다시 보기→마지막 기록→편지 전문→크레딧. Space로 원문을 펼치고 포커스 윤곽이 보이는 것을 확인했다. 버튼 높이48/48.8px, summary/크레딧44px 이상이다.
-390px에서 편지/크레딧을 펼쳐도 document가390px로 가로 넘침0이었다.1024×540도 가로 넘침0/세로 스크롤을 확인했다.
- 실제 설정 UI에서 자막150%/화면 흔들림·점멸 줄이기를 켜고 재접속했다. 엔딩의 is-still·계산된 애니메이션none/transition0s·본문21px를 확인했다. 큰 글자 편지는 native scroll로 읽을 수 있었다.
- 후일담 다시 보기로 처음부터 타이머 재생, 건너뛰기로 최종 화면 복귀, 다시 시작으로 도입 복귀를 확인했다. 타입/관련 기존 시스템 UI4개 합격. 본 변경은 시각/마크업 수정으로, 문구 정규식만 확인하는 별도 검사는 추가하지 않았다.
- 읽기 전용 검토에서 남은 차단 항목은 없었다. 실제 모바일 하드웨어·전체 스크린리더·새 플레이어 감상 평가는 별도다. 마지막 장식 clock의 aria-hidden 처리와 크레딧 링크 밑줄은 시각 구성 유지 보완이다.
