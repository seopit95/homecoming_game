# 2026-11-01 첫 접속 로딩 · 로컬 최적화

1~2초 플레이 시작은 달성하지 못했다. 네트워크가 제한될 때의 대기는 줄였지만, 모든 실제 공간을 안전하게 사전 준비하는 구조는 유지했다. 이 문서는 초기 질감 단독 로컬 대조 결과다. 이후 사용자 승인에 따른 추격 음악·엔딩 합본의 최종 실측과 공개 배포 영수증은 task/loading-20261101에 별도 기록한다.

## 변경

`loadTexture`가 논리 URL에서 14개 경량 WebP 사본을 선택한다. 원본·해상도·알파·색 공간 처리·방향·재질 설정은 유지한다. 큰 컬러 질감은 PSNR40dB 이상, 두 normal 사본은48.452/53.728dB다. ARM 채널에는 손실 압축을 적용하지 않았다. 얼굴·인쇄 글자·휴대폰 잘라낸 이미지는 바꾸지 않는다. 원본 파일/기존 라이선스를 보존하며 `scripts/author-runtime-textures.py`와 `public/textures/runtime/sources.json`에 재생성 조건·해시·픽셀 차이를 기록했다. 사본은 총17,099,764→6,713,760바이트다. 손실 압축이므로 픽셀이 완전히 같다는 뜻은 아니다.

사본이 HTTP/디코딩/전송 오류를 내면 원본으로 복구한다. 파일별 기존 전송 재시도1회는 그대로여서 최악에도 사본2회+원본2회로 유한하다. 매핑은 `assetUrl` 앞에 적용해 Sites와 itch의 하위 경로 모두를 보존한다.

## 측정 정의와 조건

메뉴의 새 게임 버튼이 활성화된 시점을 준비 완료로 정의한다. 실제 `Game.ready`의 모든 그래픽 준비가 끝난 상태이며 버튼 뒤에 새 준비 장벽을 추가하지 않는다. 시작 버튼을 누르기까지 사람의 대기 시간과 원래 이야기의 도입 연출/건너뛴 뒤4.8초 기상 연출은 로딩 시간에 넣지 않는다. 본편 자유 이동이 처음 허용되는 장면 자체를 앞당기지도 않는다.

2026-11-01 Mac의 IAB Chromium156,1280×720/DPR1, CPU 제한 없음. 각 응답 Cache-Control:no-store, 서비스 워커 없음, 새로 고침마다 HTTP 자산 재전송 확인. 같은 정적 HTML5 프로덕션 타깃·같은 계측 스크립트·동일 로컬 서버에서 전후3회씩 측정했다. 20Mbps는 서버가 모든 응답의 총 바이트를 제한한 합성 조건이며 추가 RTT는 넣지 않았다. GPU/OS/드라이버 캐시를 초기화한 실험이나 실제 이동통신망 결과는 아니다. 속도 측정 동안 다른 빌드·테스트는 겹치지 않았다.

## 검증과 남은 제한

- 관련18개 검사/타입/기존 Sites와 HTML5 빌드 합격. 새 매핑 검사는 수정 전 원본 URL 요청으로 실패하고 수정 후 사본 선택·원본 복구·유한 재시도로 통과했다. 기존 원본 전용 실패 검사는 매핑 없는 파일로 유지하고, 전체 준비 정리 검사는 사본과 원본 모두 실패하도록 갱신했다.
- 실제 브라우저에서 사본14개를 전부404로 만들어 하위 `/nested/` 경로에서 원본으로 복구한 뒤 저장 이어하기·이동·시점 조작을 확인했다. 사본 정상 경로에서도 같은 저장과 빛/벽/바닥/손을 확인했다. 예상한 결함 주입404 외 미처리 rejection은 없다.
- 20Mbps 후보에서 새 게임 시작 후30초:1815프레임, 중앙값16.7ms/p9517.5ms/최대17.7ms,50ms 초과0, 시작 후 새 이미지 요청0, JS/HTTP 오류0. 본편 건너뛰기와 이동도 확인했다. 단일 구간 증거이며 전체 캠페인·실제 모바일·직접 음향 청취 인증은 아니다.
