# 목표 발견성과 HUD 정리 — 로컬 변경

오른쪽 위 기록/전체 화면/일시정지 표시를 제거했다. 왼쪽 아래의 메뉴 버튼과 ESC/P, J 수첩을 유지하고 전체 화면은 일시정지의 환경 설정으로 옮겼다. 메뉴는 영화 장면 레이어 위에서도 접근한다.

새 목표는 중앙의 이름 있는 polite status로 5.5초 동안 표시하고 왼쪽 위에 현재 목표를 남긴다. 타이머는 게임 경과 시간을 쓰므로 일시정지 중 소진되지 않는다. tv/wake_ring과 전환 페이드에서는 안내를 시작하지 않는다. 미션 변경과 저장 이어하기는 새로운 안내를 만들고, 같은 미션에서 메뉴만 열고 닫으면 이미 끝난 안내를 반복하지 않는다. 흔들림/강한 점멸/새 소리를 추가하지 않았다. 한국어 단어 줄바꿈, 자막 크기 설정, 모션 줄이기와 선택형 목표 표시를 유지한다.

`GameView.mission`은 기존 `objectiveFor(story)`와 키 설정 치환을 사용하며 저장하지 않는 파생 값이다. 통화/재생/은신의 일시 상태인 `view.objective`와 분리했다. 중앙에는 실제 미션만 안내하고 임시 상태는 왼쪽 위 보조 문구로 둔다. 일시정지와 수첩에서는 목표 표시 옵션을 꺼도 실제 미션을 확인할 수 있다. 저장 형식·동선·체력·음향은 변경하지 않았다.
