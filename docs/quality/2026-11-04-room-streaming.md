# 2026-11-04 첫 공간 우선 준비

## 변경

첫 집, 손/스마트폰, 보존된 도입 운전 장면에 필요한 이미지 41개(21,600,933바이트)만 초기 준비한다. 기존 초기 이미지는 50개(25,522,319바이트)였으며 9개/3,921,386바이트를 다음 공간 준비로 옮겼다. 원본·압축 전송본·원본 복구 경로는 삭제하지 않았다.

`visual-stages.json`은 실제 생성한 공간의 재질 이미지에서 수집한 목록이다. `prepareVisuals('initial')` 이후 공간별 준비는 이미 성공한 소스를 재사용하고 겹치는 배치를 직렬화한다. 실패한 배치는 새로 받은 미발행 비트맵만 정리하고 앞선 방의 소스는 유지한다. 기본 전체 준비와 은퇴한 제작용 자료도 보존한다.

`Game.ready`는 첫 집과 도입 도로만 기다린다. 첫 시작과 각 공간 입장 후 가까운 다음 공간을 별도 장면/카메라로 생성·컴파일한다. 이미지 업로드 사이에는 양보한다. 이동/추격 중 새 공간의 무거운 생성은 안전한 시점이나 진입 대기까지 미루며 이미지 전송은 먼저 진행한다. CCTV 별도 장면, 승강기 변형, 주차장 출차/마지막 도로 결합도 준비한다. 캐시된 마지막 도로는 재사용한다.

목적지가 준비되지 않았으면 기존 공간을 유지하고 시뮬레이션·추격·오디오·입력을 멈춘다. 같은 프레임의 후속 추격 처리와 문턱 좌표 변환도 중단한다. 준비 성공 후 기존 전이를 한 번 실행한다. 수동 일시정지와 숨긴 탭 상태를 존중한다. 실패하면 재시도 버튼을 제공한다. 종료 시 진행 중 컴파일이 끝난 뒤 GPU 자원을 해제한다.
