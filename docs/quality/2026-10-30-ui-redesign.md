## 일시정지와 기록

`PauseMenu`는 native dialog로 현재 플레이를 가리고, 왼쪽의 계속하기·환경 설정·조사 수첩·재시작과 오른쪽 내용을 나눈다. 설정은 기존 슬라이더/체크박스/키 재설정을 그대로 받는다. 조작 설명은 필요할 때 펼친다. 수첩의 사실 시간대와 원문을 큰 화면에서는 두 열, 작은 화면에서는 한 흐름으로 읽는다. 둥근 카드/글로우/외부 이미지·웹 폰트를 추가하지 않았다.

Tab/Shift+Tab 경계는 메뉴 안에서 순환하고, ESC로 닫으면 이전 버튼에 포커스를 돌린다. 실제 브라우저에서 모달 여부, 양쪽 순환과 일시정지 버튼 복귀를 확인했다. 메뉴의 CSS 표본5개는 뒤 장면을 흰색으로 가정한 대비 계산에서 최소7.05:1이다. 전체 WCAG 적합 인증을 뜻하지 않는다.

검토에서481–560px 높이의 기존 수첩 CSS와 새 부모 overflow가 충돌하는 것을 확인해 compact 분기를560px까지 맞췄다. 실제1024×540에서 scrollHeight632/clientHeight508, scrollTop124로 끝까지 접근한다.390×844에서는 dialog scrollHeight2631/clientHeight844, scrollTop1787로 마지막 원문까지 읽고 가로 넘침이 없었다.

## 키보드 입력 보존

기존 게임은 paused 판정 전에 방향키/Space를 preventDefault해 슬라이더와 버튼의 기본 키 조작을 막았다. 두 실제 게임 RED 검사로 재현했다. 공유 keydown에서 메뉴/엔딩과 일반 HTML 버튼의 기본 키를 먼저 존중하되 Escape/P는 기존 일시정지 동작을 유지한다. `data-game-interaction`이 있는 두 상호작용 버튼은 기존 Space 게임 입력을 유지하므로 문 벌리기·탑승 길게 누르기를 빼앗지 않는다. 정적 빌드에서 HUD Space로 메뉴 열기, 방향키로 음량42→43→42%를 확인했다.

이 과정에서 발견한 옛 테스트 시간 단정만 현재 게임에 맞췄다. 체력 사용6.7초→9.4초는 이미 커밋된 V135의 연속 달리기9.2초를 검사하며, 탑승 취소0.25초→0.075초는 기존 탑승0.2초보다 짧게 누른다. 게임 수치·동선·저장 스키마는 바꾸지 않았다.
