# 미션 문구·영역의 공포 분위기 개선
+
+중앙 표제는 「잊지 마.」, 상시 미션 표제는 「해야 할 일」로 다듬었다. 첫 줄의 실제 행동을 강조하고 둘째 줄의 불길한 문장을 작게 분리한다. 예: 「다용도실 배전반을 확인한다. / 타는 냄새가 난다. 우리 집만 어둡다.」 현재 주 동선의 명령·위치·남은 기록 수·사용자 키 치환을 유지한다. 라디오는 실제 목표의 「끄기」, 탑승은 짧은 E 조작, 경보기는 종료 전후 시점에 맞춰 표현했다. 이야기·맵·입력·위협/저장 로직은 바꾸지 않았다.
+
+거친 가장자리와 작은 가로 결은 CSS 배경에만 적용하고, 명조체 표제/탁한 적갈색 선/먹색 바탕을 사용한다. 본문은 기존 읽기 쉬운 고딕체이며 글자 손상·빛 번짐·점멸·새 소리·외부 이미지·폰트는 추가하지 않는다. 밝은 장면에서도 글자 뒤에는 진한 배경이 남는다.
+
+중앙 안내의 5.5초 게임 시간/전환 가림 억제/일시정지 보존, 상시 목표·수첩 확인, 힌트/큰 글자/모션 줄이기를 유지한다. 중앙 안내 중에는 상시 목표의 중복 시각·접근성 표시를 잠시 숨기고 안내가 끝나면 다시 보인다. HUD 오른쪽 위 표시는 복원하지 않는다.
+
+## 검증
+
+- 관련 렌더/현행 기록 수집/이야기·수첩 검사22개 합격. 시스템 UI4개에 실제 행동 강조/분리와 named polite status가 포함된다. 타입 검사 합격.
+- 처음 넓게 실행한28개 중6개는 옛 stairs/resident/office 경로 단정으로 실패했다. 수정 전1797c88의9개 파일을 별도 디렉터리에 읽기 전용으로 복원해 똑같은6개 실패를 확인했다. 실패 이름 비교는 `eerie-mission-evidence/baseline-comparison.json`. 이6개를 제외한 관련22개는 종료0/실패0이다. 과거 전체 suite가 합격했다고 주장하지 않는다.
+- 실제 HTML5:1280×720 중앙 행동/분위기 문장,390×844 큰 글자150%/모션 줄이기/coarse CSS,1024×540의 긴 목표와 메뉴·수첩을 확인했다. 세로 안내 하단512px와 터치 영역 상단683px 사이 여유, 가로 안내163–301px/가로 넘침0. 접근성 트리에서 중앙 안내 중 중복 상시 목표가 숨겨짐을 확인했다.
+- 기존 V140 미션 시간·키보드/진행·음향 검사 중 바뀌지 않은 부분은 재사용한다. 최종 웹·HTML5 로컬 빌드/ZIP/캡처 정보는 task의 `eerie-mission-evidence`와 `itch-release/release-state.json`에 기록한다.
+
+실제 휴대전화·스크린리더 전체·신규 플레이어 사용성 평가는 미실시다. coarse CSS는 로컬 검증 보조 파일로만 실행하며 ZIP에 넣지 않는다. 공개 웹136/원격 소스는 바꾸지 않고 itch 업로드도 대기한다.
