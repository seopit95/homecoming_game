# 2026-11-06 공포게임 피드백 수정

## 변경 범위

- 장롱 수색을 마치고 귀신이 실제로 퇴각한 뒤 정확한 하단 중앙 대사 **차키가 거실 탁자에 있는데...**를7초 표시한다. 장롱에서 나온 직후에도 차키가 없으면 같은 단서를 유지한다. 기존 수동 미션 편지/수첩 UI를 보존한다.
- 거실 탁자 위에 실제 차키를 배치했다. 수색 완료 전이나 장롱 안에서는 획득할 수 없으며, 획득 뒤 현관 출발로 목표와 기록이 바뀐다. 차키 없이는 현관 통과를 할 수 없다. 키를 찾는 동안 귀신은 먼 방에 머물고, 획득 후 기존 추격으로 이어진다. 접촉 판정은 유지한다.
- 주차장 조수석 문/가방에서 키를 찾는 상호작용과 중복 키 표시를 제거했다. 집에서 챙긴 키로 바로 운전석에 탑승한다. 현재 지하 동선은 배수 퍼즐을 요구하지 않는다. 과거 외부/주차장 저장은 키 보유·현재 동선으로 이관한다.
- 완료한 장롱 수색/키 획득이 재시도·이어하기에 보존된다. 재은신한 wait 상태를 radio로 저장하던 경계 오류도 수정했다. 첫 수색을 끝내지 않은 재시도는 이전대로 유지한다.
- 연속 달리기10.12→15초(+4.88초, 약48%). 입력을 계속 누를 때 소진 후 회복이 막히지 않고, 임계값의 부동소수점 오차로 상태가 어긋나지 않도록 했다. 화면 값은0–100%로 제한하고 달리기 가능/숨 고르기를 구별한다. 기존1.5초 회복 지연,25% 해제(소진 후3.75초),9초 실제 재충전(총10.5초)은 유지했다.
- 외부 평시 추격은 걷기보다 빠르고 달리기보다 느리게 조정했다. 짧은 돌진과 사전 비명은 유지하므로 계속 걷기만 해도 안전한 구조는 아니다. 계단/20F 진입4초, 주차장6초 방향 확인 시간을 둔다. 이전에 벌린 추격 거리는 저장·경보 조작에도 보존한다. 경보는 선택 사항이며5초 뒤 꺼진다.
- 20F 계단 샤프트 아래 바닥, B1 계단 측면 바닥과 끝벽의 빠진 띠·이음부를 실제 geometry로 막았다. 안개로 가리지 않았다. B1/중간층 출구 표지의 누락·높이도 수정했다.
- 새 대사·목표·기록·HUD 상태를 기존 한국어/영어/일본어/중국어 간체에 반영했다. 이전 공간 우선 로딩과 외부 귀신의 벽/바닥 이동을 유지했다.
