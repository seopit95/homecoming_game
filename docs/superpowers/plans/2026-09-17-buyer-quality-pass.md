# 구매자 관점 완성도 개선 계획

목표: 실제 장면에서 제작 흔적이 드러나는 부유·관통·설치 오류를 수정하고, 기존 일곱 장의 단서와 공간 이동 사이 인과관계를 정리한다. 새로운 의존성이나 별도 게임 시스템은 추가하지 않는다. 현재 Site와 접근 범위를 유지한다.

- [x] 가구 접촉 회귀 검사: 집/1704호 책상 다리, 소파 발, 사무실 모니터 받침, 벽 스위치·분전반, 펌프 제어함의 실제 기하 접촉을 확인한다.
- [x] `world.ts`, `japan.ts`, `building.ts`, `chapters.ts`: 바닥부터 받침·본체·소품으로 이어지는 구조를 만들고, 벽 장착물은 벽면에 맞춘다. 선반은 속이 빈 프레임, 사무실 책상은 실제 책상 형태로 바꾼다. 이동·추격 통로는 보존한다.
- [x] `story.ts`, `game.ts`, 장면 소품: 출구 대사 분기, 계단/1704호/관리실 연결 단서, 열쇠의 출처, 마지막 차량 방향을 일치시킨다. 단서를 일지에만 두지 않고 실제 공간에 배치한다.
- [x] 실제 조명 아래 근접 장면과 모든 주요 공간을 렌더링해 확인한다. 전체 회귀 검사, 타입 검사, 빌드를 실행하고 독립 코드 리뷰의 중요한 문제를 해결한다.
- [ ] 구매자 기준 보고서에 수정 완료와 남은 출시 과제를 구분한다. 검증한 소스를 같은 Site에 게시한다.

검증: 전체 78개 검사 통과, 타입 검사와 배포용 빌드 통과. 실제 브라우저 1280×720 / 390×844에서 깨짐·실행 오류 없음. 근접 장면 11개 확인. 독립 검토의 경보 유인 좌표와 잔해 제거 시점 수정 후 재확인 완료. 게시 완료 여부는 Sites 배포 결과로 확인한다.
