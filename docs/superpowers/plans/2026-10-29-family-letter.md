# 아내의 편지 이야기 적용 계획

사용자가 승인한 이야기: 행복했던 부부와 아이, 사업 실패와 빚 뒤 남편의 음주, 끝까지 돕던 아내의 장보기 귀갓길 사고. 관리실 세 상호작용에 아내의 노력을 담고, 기존 도주·조수석 귀신·트럭 충돌 후 경찰의 다시방 편지 발견으로 연결한다. 공개 배포와 업로드는 금지한다.

1. 기존 격리 작업공간 `codex/reference-ghost`와 깨끗한 기준 `da309e0`을 유지한다. 임시 복사본에서 필요한 파일만 준비한다.
2. 기존 단서 ID와 3개 수집/CCTV/추격 조건을 유지한다. `family-story.ts`에 사진·상담 메모·관리실 전달 쪽지와 사고 전 작성한 편지를 모은다. `expansion-story.ts`, `ground-support.ts`, `apartment-route.ts`, `game.ts`, `story.ts`, `investigation.ts`의 실제 표시만 연결한다. 이름을 알기 전/단서를 읽기 전 수첩에 진실이 새지 않게 검사한다.
3. `ending-screen.tsx`의 기존 사고 보고·빈 조수석 후일담에 경찰의 다시방 조사·편지 전문을 표시한다. 다시 보기·건너뛰기·잡힘 재시도는 보존하고 긴 편지의 읽을 시간을 확보한다.
4. 실제 단서 수집과 수첩의 공개 범위를 검사한다. 기존 방/자료 도달성·관리실 안전·마지막 충돌 검증을 재사용/선택 실행한다. 타입 검사·운영 빌드와 실제 Chrome에서 세 단서 및 후일담 표시를 확인한다. 기능별 한글 커밋을 남긴다.
5. 변경 없는 이동/전투/모델은 재설계하지 않는다. 기억 혼란을 확정적인 진단명으로 설명하지 않으며, 음주운전·구조 거부·은폐의 책임을 남긴다. 1704호 옛 동선에만 새 핵심 단서를 놓지 않는다. itch.io 내보내기 증거는 원본과 분리한 실험 자료로만 보고한다.
